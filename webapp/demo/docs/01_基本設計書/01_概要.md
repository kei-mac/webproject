# 基本設計（サーバ処理）概要
基本設計書のサーバ処理の概要について記載する。

## 構成
構成としては、Spring Bootのような構成とする。
ただしSpring Bootは使用せずに下記の使用とする。
- Injectionを使用する。そのため、以下のような記載ができるものとする。
- 依存注入し、コンストラクタ記載を不要となるようにする。
  ``` Java
  package com.kitafw.demo;


  // Inject
  @XXXXXXXX{onInject=XXXX}
  public class DemoApplication {

    // コンテナに依存注入（コンストラクタ記載を不要とする。）
    private final MapperClass mapper;

  	public static void main() {
  		// 処理を記載
  	}

  }
  ```
