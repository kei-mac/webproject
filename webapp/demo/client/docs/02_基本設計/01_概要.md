# FW基本設計書
FWの基本設計書を記載する。

## HTMLファイルについて
htmlは、以下の2つとする。
下記以外のhtmlはなしとし、動的にＨＴＭＬを作成するものとする。
| No | ファイル名 | 概要 |
| -- | -- | -- |
| 1 | index.html | 一番最初に呼び出しされて、ログイン画面に遷移します。 |
| 2 | login.html | "ログイン"ボタンを押下することで、システムののトップメニュー画面に遷移します。 |

## APIについて
### URLの構成について
REST APIの設計とします。
URLの構成は以下の通りとする。
**http://kita_fw/{menu}/{content}/{content_element}/select={id}**

### APIについて
apiは、共通で以下とします。
| No | qpiパス | 詳細 |
| -- | -- | -- |
| 1 | qpi/search | 検索用のAPI |
| 2 | qpi/add | 追加用のAPI |
| 3 | qpi/update | 更新用のAPI |
| 4 | qpi/delete | 削除用のAPI |
